# DailyBrief Learn — M0

## Confirmed scope

- Spanish only; beginner content is tagged A1.
- One topic per generated lesson, with 10 new words by default.
- Lesson snapshots are generated by the LLM and validated before rendering.
- No learning-state persistence in M0.
- A lesson contains one topic. The LLM selects common, high-frequency A1 words and continues the previous topic while it can generate 10 non-repeated items for that topic.
- A standalone `Hola!` page is linked below the archive link in web-mode daily reports and from the archive page.
- Lesson content is generated for DailyBrief Learn. Third-party phrasebook text is not copied into the repository.
- Chinese meanings remain in the lesson data while the UI flag in `scripts/language/render-page.mjs` is off.

## M0 artifacts

- `data/language/topics/taxonomy.json`: three starter topics and ordering.
- `data/language/schema/daily-lesson.schema.json`: JSON Schema contract for lesson snapshots.
- `npm run language:check`: validates the topic taxonomy and lesson schema.
- `npm run language:generate [YYYY-MM-DD]`: generates and stores a Spanish lesson without running the news pipeline.
- `daily_reports/language/lessons/YYYY-MM-DD.json`: generated lesson snapshots; these are retained on the published `gh-pages` branch.
- `daily_reports/language/used-words.json`: ignored local/published derived index, rebuilt from lesson snapshots and used for deduplication.
- `npm run build-site`: emits `daily_reports/hola.html` along with the existing static site pages.
- A new report run makes one additional LLM call for the lesson. If it fails validation twice, the news report still publishes and Hola! keeps the latest successful lesson; before the first successful generation, the page shows an empty-state message.

## Next iterations
